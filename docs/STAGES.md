# GIO stages

Generated by `npm run report:stages`. Do not edit by hand.

Difficulty is the complexity of each quest's reference solution (statements, nesting, procedures, inputs, recursion, key handlers, variables and conditions, primitive families, ticks played, hidden calls and property checks; see `src/logo/difficulty.ts`). Tests require the stage number and the mean difficulty to rank together (see the rank correlation under each table), the second unit of every stage to be at least as hard as the first, no stage to fall below 80 per cent of the stage before it (apart from the named exemptions), and the last stage to be the hardest. The "small on purpose" stages are about writing the fewest commands, so their code is short and their difficulty is shown by the wasteful answers that must fail. The difficulty does not rise in every single step: the dips are listed under each table.
