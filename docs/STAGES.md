# GIO stages

Generated by `npm run report:stages`. Do not edit by hand.

Difficulty is the complexity of each quest's reference solution (statements, nesting, procedures, inputs, recursion, key handlers, variables and conditions, primitive families, ticks played, hidden calls and property checks; see `src/logo/difficulty.ts`). Tests require the stage number and the mean difficulty to rise together, and the second unit of every stage to be at least as hard as the first. The two "small on purpose" stages are about writing the fewest commands, so their code is short and their difficulty is shown by the wasteful answers that must fail.
